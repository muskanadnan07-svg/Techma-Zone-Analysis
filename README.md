# 📊 Techma Zone Institute Dashboard

An interactive **Power BI dashboard** designed to analyze student enrollment, courses, batches, placement performance, student demographics, and learning modes at **Techma Zone**.

The dashboard provides a clear overview of institute performance and helps identify trends in student strength, course popularity, placements, and student distribution.

---

## 🎯 Project Objective

The main objective of this project is to create an interactive institute management dashboard that provides useful insights into:

- 👨‍🎓 Total student strength
- 📚 Course-wise enrollment
- 🏫 Total and active batches
- 📈 Monthly enrollment trends
- 💼 Student placement performance
- 🌍 Pakistan vs Overseas students
- 🗺️ Student distribution by area
- 👩‍💻 Student strength by gender
- 💻 Online vs Onsite students
- 📊 Course performance
- 📌 Course enrollment and status
- 🏆 Passed vs Placed students

## 📈 Dashboard Insights

### 👨‍🎓 Student Overview

The dashboard contains **6,000 students** across different courses and batches.

Students are divided between:

- Online learning
- Onsite learning
- Pakistan
- Overseas

---

### 📚 Course Performance

The dashboard analyzes the performance of the following courses:

- Applied Data Science & AI
- Business Intelligence
- Data Analytics Fundamentals
- Data Engineering
- Generative AI
- Machine Learning

The **Course Performance Summary** compares:

- Enrolled students
- Passed students
- Placed students
- Placement rate

---

### 💼 Placement Analysis

The dashboard compares students who successfully passed their courses with students who were placed.

This helps identify courses with stronger placement outcomes and provides an overall view of institute placement performance.

---

### 🌍 Student Geographic Distribution

The dashboard highlights the top areas based on student strength.

Some of the major areas represented include:

- Dubai
- Sharjah
- Dammam
- Abu Dhabi
- Riyadh
- Manchester
- Saddar
- Bahadurabad
- Clifton
- Korangi

---

### 💻 Learning Mode

Student strength is also analyzed according to learning mode:

- Online
- Onsite

This provides an overview of how students prefer to attend their courses.

---

### 👩‍🎓 Gender Analysis

The dashboard includes student strength by gender to provide a demographic overview of the institute.

---

### 📅 Monthly Enrollment

The monthly enrollment chart shows changes in student enrollment throughout the year.

This can help identify:

- High-enrollment months
- Low-enrollment periods
- Seasonal trends
- Potential admission campaign opportunities
